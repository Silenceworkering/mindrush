# MindRush

Telegram Mini App на русском: одиночная викторина, XP, нейроны, рейтинг, ручные награды и Premium за 49 Stars/30 дней.

Для запуска на Render: `npm install` / `npm start`; переменные `DATABASE_URL`, `BOT_TOKEN`, `PUBLIC_URL`, `WEBHOOK_SECRET`. После запуска настройте Web App в BotFather и webhook POST на `/telegram/webhook` с заголовком secret token. Не публикуйте токен.

PvP и турниры ещё не реализованы. Внутренняя валюта не покупается и не выводится. Продакшен-платежи требуют проверки в Telegram.
